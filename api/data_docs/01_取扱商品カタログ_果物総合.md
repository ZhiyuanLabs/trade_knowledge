## 商品コードの読み方

FRT-(果物略称)-(連番) の形式。例：FRT-BAN-001 はバナナ、FRT-STR-002 はいちご（ストロベリー）、FRT-KIW-001 はキウイ。受注番号は SO-2026-xxxx、入荷番号は RC-7xxx、出荷番号は SH-9xxx。
