# 株式会社サン・フレッシュ・トレーディング 会社概要

当社は生鮮果実（青果物）を主力とする総合商社であり、海外産地からの輸入・植物検疫手続、国内産地からの集荷、選別・カット加工、冷蔵保管、大手スーパー・生協・コンビニへの卸売と納品までを一貫して手がける。本書は業務エージェント（Agentic RAG）が参照する社内ナレッジの総合窓口である。

- 生鮮果実の輸入販売（バナナ、柑橘、キウイ、マンゴー、アボカド、ベリー類など）
- 国産果実の集荷・卸売（りんご、みかん、いちご、ぶどう、メロン、すいかなど）

- 季節催事（クリスマス、お歳暮、お盆）向けの専用商品供給と緊急・特急対応
