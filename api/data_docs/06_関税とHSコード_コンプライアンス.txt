================================================================
関税とHSコード（果物・コンプライアンス）
================================================================


【1. 果物は「第08類」】
生鮮・冷蔵・冷凍の食用果実は HS コード第08類に分類される。通関は食品等輸入届出済証を得た後、税関へ輸入申告して関税を納付する。原産国は原産地証明書で証明し、EPA（経済連携協定）を利用する場合は所定の原産地証明書を添付する。


【2. 代表品目の関税上の留意点】
・バナナ：季節関税の対象で、輸入時期により税率が異なる。
・オレンジ：ネーブル・バレンシアなどで季節関税が適用される期間がある。
・グレープフルーツ：同様に季節関税の対象となる。
・パイナップルの缶詰など加工品は関税割当制度（一定枠内で低税率、枠外は高税率）の対象となる。
・EPA（日欧・TPP11・RCEP・日フィリピンなど）では、条件を満たせば引き下げ・無税の場合がある。


【3. 検疫と関税の両方を確認する】
関税の前に植物検疫・食品衛生の条件を満たす必要がある。特にミバエ類の発生国・地域からは生果の輸入が禁止されることがあり、「輸入できる国・品目か」を関税より前に植物検疫で確認する。

・チチュウカイミバエ、ミカンコミバエ、クインスランドミバエ、ウリミバエの発生地域からの該当寄主の生果は原則輸入禁止。
・条件付き解禁：指定園地、栽培地検査、コールド処理（冷処理）、蒸熱処理等を満たした場合に限り輸入可能。
・検疫対象外の乾果：バナナ、パイナップル、マンゴー、キウイなどの乾燥果実は植物検疫の対象とならない場合がある。


【4. 社内確認チェックリスト】
・HSコード（第08類の該当番号）と適用税率（一般/暫定/WHO協定/EPA）
・季節関税の適用期間、関税割当の枠の有無
・原産地証明書（EPA利用の場合）
・植物検疫証明書・食品等輸入届出済証の準備
・検疫対象品目かどうか（指定園地・コールド処理等の条件確認）
