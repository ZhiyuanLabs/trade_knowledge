## 2. クリスマスのいちご（最重要）

- ケーキ用途でいちご需要が12月に集中する。栃木「とちあいか」、福岡「あまおう」を主力とする。
- 10月末までにケーキ工場・量販店から予約を受け、産地枠と入荷（RC-7004 は12月15日入荷予定）を確保する。
- 猛暑などで作柄が悪化すると不足・高騰する。実際に栃木産いちごのクリスマス不足が報道される年もある。
- 受注例：SO-2026-1101（イオン向けとちあいか120箱、納品期限12月18日）。
- 不足時は空輸いちごへの切替、冷凍いちご（ケーキの中身）への代替、サイズ変更を提案する。

## 3. お歳暮ギフト

- 紅まどんな（愛媛）、シャインマスカット（長野）、みかん詰合せ、いちごを化粧箱・熨斗で12月に供給。
- 受注例：SO-2026-1103（コープ向け紅まどんな80箱、納品期限12月5日）。入荷RC-7005は11月25日予定。
- ギフトは冷蔵便・緩衝包装・熨斗対応が必須で、大田セントラルパッキングのギフトラインを使う。
