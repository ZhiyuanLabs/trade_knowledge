## 3. 調達のポイント

- 南半球（チリ、NZ、南アフリカ、豪州、ペルー）産は北半球の冬〜春に旬を迎え、国産の端境期を補う。
- バナナ・パイナップルはリーファー船でコストを抑え、ライチ・マンゴー・ベリー・さくらんぼは鮮度優先で航空便を使う。
- 旬の短いライチ・さくらんぼは入荷枠が限定されるため、事前予約と発注点管理が必須である。
- クリスマスのいちご、12月の紅まどんな・シャインマスカット（歳暮）は特需で早期予約が必要（「20_繁盛期カレンダー」参照）。
