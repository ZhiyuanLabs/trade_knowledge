# 用語集（生鮮果実・輸入・物流）

## あ行

- アレルゲン：食品表示で義務されるアレルギー物質（特定原材料等）。
- 安全在庫（safety stock）：需要変動やリードタイム遅れを吸収するための最低在庫。
- EAN/JAN/GTIN：商品バーコードの規格。店舗発注・レジに使用。
- 入荷予定（ETA）：貨物が倉庫に入る予定日。入荷番号 RC-7xxx で管理。
- ASN：事前出荷通知。納品先に送る出荷明細。
- AWB（航空運送状）：航空貨物の運送契約書類。

## か行

- 階級：青果物の大きさ（2S・S・M・L・2L・3L、玉数）。
- カットフルーツ：カット・パックした加工食品（消費期限・10℃以下管理）。
- ギフト（歳暮・中元）：化粧箱・熨斗の詰合せ。催事期に集中。
- CA（CA貯蔵・CA輸送）：酸素・二酸化炭素濃度を調整し、呼吸と追熟を抑える技術。
- MA包装：包装内のガスを調整し鮮度を保つフィルム包装。
- コールド処理（冷処理）：果実を低温で保持しミバエ幼虫を殺す検疫処理。
- コールドチェーン：産地から店頭までの連続した冷蔵温度管理。
- コールドチェーン：品目別に0-2℃、5-10℃、13-15℃などの温度帯を使い分ける。

## さ行

- 産地証明（原産地証明書）：原産国を証明する書類。関税・EPA・表示に使用。
- シーズン（季節）関税：バナナ・オレンジ・グレープフルーツなどに適用される期間別税率。
- 関税割当：枠内は低税率、枠外は高税率となる制度（パイナップル缶詰など）。
- くん蒸（薫蒸）：ガスで検疫害虫を駆除する消毒処理。
- 検査命令：食品衛生法でリスク品目に輸入都度義務付ける検査。
- ポジティブリスト：残留農薬等の基準（未設定農薬は一律0.01ppm）。
- HACCP：危害分析・重要管理点に基づく衛生管理。
- HSコード：物品の分類番号。果物は第08類。
- 蒸熱処理：蒸気・熱でマンゴーなどのミバエ幼虫を殺す処理。
- GAP/GLOBALG.A.P.：農産物の生産工程管理認証。
- 消費期限：傷みやすい食品（カット果実）の期限。
- 賞味期限：品質保持の期限（冷凍果実など）。
- 発注点：発注を行う在庫水準（リードタイム需要＋安全在庫）。
- 発注リードタイム：発注から入荷までの期間（船便は数週間、空輸は数日）。

## た行

- 追熟：バナナ・アボカドなどをエチレンで追熟室（18-20℃）で熟させる工程。
- 低温障害（チリングインジュリー）：熱帯果実が低温で皮黒変・傷む現象。
- 等級：青果物の品質（特秀・赤秀・青秀/秀・優、Extra/Class I/II）。
- ドリップ：カット果実から出る離水。
- DC：在庫を保有する配送センター。TC：通過型の仕分けセンター。
- Brix（糖度）：光センサー選果機で測る糖度。
- NACCS：通関・検疫の電子申請システム（APSで検疫申請）。

## は行

- バース：配送センターの荷受けホーム（時間予約制）。
- パックハウス（packhouse）：輸出産地で選別・包装・予冷する施設。
- B/L（船荷証券）：海上貨物の運送契約書類。
- 食品等輸入届出済証：食品衛生法の届出・検査を経た証明。
- 植物検疫証明書：輸出国植物検疫機関が発行する必須の検疫証明（phytosanitary certificate）。
- phytosanitary certificate：植物検疫証明書の英語名。

## ま行

- ミバエ（チチュウカイ/ミカンコ/クインスランド/ウリミバエ）：生果輸入を制限する検疫害虫。
- モニタリング検査：輸入食品を統計抽出で行う行政検査。

## や行以降・英数字

- リーファー（reefer）：冷凍・冷蔵コンテナ（またはトラック）。
- リードタイム：発注から入荷までの期間。
- IQF：個別急速冷凍（バラ凍結の冷凍果実）。
- EPA：経済連携協定。条件を満たすと関税が引き下げ・無税。
- エチレン：果実が追熟を進めるガス。バナナとりんご・梨の同梱を避ける。
- KMnO₄/ゼオライト：エチレンを吸着除去する資材。
