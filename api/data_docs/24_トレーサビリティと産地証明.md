# トレーサビリティと産地証明

青果物の安全・品質トラブルでは、産地から店頭までの双方向の追跡（トレーサビリティ）が求められる。入荷・加工・出荷・受注の番号をつなぎ、証明書と紐付ける。

## 1. ロット番号のつながり

| 段階 | 番号・帳票 | 記録する内容 |
| --- | --- | --- |
| 輸入・産地 | 入荷番号 RC-7xxx | 原産国・産地・packhouse・収穫/船積日・検疫証明書 |
| 保管 | 入庫ロット・棚番 | 倉庫・温度記録・入庫日 |
| 加工 | 加工ロット（LOT-日付-時刻） | 原料ロット・加工場・ライン・消費期限 |
| 出荷 | 出荷番号 SH-9xxx | 出荷日・数量・配送便・温度ロガー |
| 販売 | 受注番号 SO-2026-xxxx | 販売先・DC/店舗・納品日 |

## 2. 紐付ける証明書

- 植物検疫証明書（phytosanitary certificate）：輸入青果物に必須。
- 原産地証明書（Certificate of Origin）：原産国・EPA税率の根拠。
- 有機JAS証明・GLOBALG.A.P.認証：有機バナナやPB要件で使用。
- 加工場のHACCP・ISO22000/FSSC22000の管理記録。
- 温度ロガー記録（リーファー・追熟室・冷蔵配送）。

## 3. 追跡の実行

- 店舗からクレームを受けたら受注番号から出荷・加工・入荷ロットを遡る（遡及）。
- 産地で問題が判明したら入荷番号から出荷・納品先を順にたどり、対象を回収する（追跡）。
- 例：RC-7001（バナナ480箱）→追熟ロット→SH-9xxx→SO-2026-1102（業務スーパー）。

## 4. 記録保存とリコール

入荷・加工・出荷・表示の記録は法令・取引要件に従って保存（少なくとも消費期限経過後まで、社内では3年を目安）する。リコール時はロット単位で回収範囲を限定し、保健所・取引先に報告する。
