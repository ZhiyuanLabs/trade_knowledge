# 納品先マスタ（配送センター・バース・受付）

各販売先の配送センター（DC）、受付時間、バース予約、納品時刻をまとめる。TC（通過型）は入荷した貨物を店舗別に仕分けして即時出荷するセンター、DCは在庫を保有するセンターである。

## 2. 納品の段取り

- 納品前日までにASN（事前出荷通知）を送り、バース・時間を予約する。
- 冷蔵便は品温記録（温度ロガー）を添付し、温度帯ごとのバースに接車する。
- 店舗別・規格別に仕分け済みで納品し、TCでは通過させるだけにする。
- バースの時間を逸すると次便へ回り、生鮮では品質劣化・欠品に直結する。

## 3. 直送とセンター便

量販店・コンビニは原則センター便（DC/TC経由）。一部の大型店・催事場は店舗直送となる。催事（クリスマス・歳暮）は専用バースと時間枠を確保するため、10月末までの予約を必須とする。
